# Chapter 2: AI Basics

## Core AI Techniques

### 1. Search Algorithms

AI systems use various search algorithms to find solutions to problems:
- Breadth-first search
- Depth-first search
- A* algorithm

### 2. Knowledge Representation

How AI systems store and use information:
- Semantic networks
- Frames
- Ontologies

### 3. Reasoning Systems

Methods for making logical inferences:
- Rule-based reasoning
- Probabilistic reasoning
- Fuzzy logic

## Practical Applications

These basic techniques form the foundation for more advanced AI applications.
