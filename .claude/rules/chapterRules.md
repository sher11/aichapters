# Chapter Rules for Staff-Level FAANG Interview Prep

## Format & Structure
- Keep chapters short, crisp, and cheatsheet-style for quick revision
- Use bullet points, tables, and diagrams over lengthy paragraphs
- Include Mermaid diagrams for visualizing flows, architectures, relationships, and algorithms
- Include a "Key Takeaways" section at the end of each chapter
- Add time/space complexity for all algorithms and data structures
- Focus on key concepts which are discussed in interviews               

## Content Depth
- Target staff-level (L6/E6) interview expectations at FAANG companies
- Cover trade-offs and when to use one approach vs another
- Include real-world system design considerations and scale implications
- Address edge cases and failure scenarios

## Interview Relevance
- Highlight commonly asked patterns and variations
- Include example interview questions with solution approaches
- Note which topics are high-frequency vs rare in interviews
- Add "gotchas" and common mistakes to avoid

## Revision-Friendly
- Start each topic with a one-liner summary
- Use mnemonics or memory aids where applicable
- Include quick self-test questions for active recall 

## Include Q&A chapter too for each chapter for revision
